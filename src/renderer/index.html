Three commands. That's the whole product.


          

            
Commands

            

              yo <name>
              Save the current session. Captures what's happening in the active panel and stores it as markdown.
            

            

              sup <name>
              Recall a saved context. Also: sup list, sup search <term>, sup forget <name>
            

            

              dip <panel>
              Switch to an AI panel. Also: dip back, dip list, dip split <a> <b>, dip refresh, dip zoom <n>
            

            

              yo help
              Open this page

Splits & Layouts

            

              dip split <a> <b>
              Side-by-side two panels
            

            

              yo layout save <name> <panels...>
              Save a custom layout. e.g. yo layout save research claude gemini gpt
            

            

              dip <layout-name>
              Apply a saved layout
            

            

              yo layout list
              Show all saved layouts
            

          


          

            
Skills

            

              yo skill create <name> <prompt>
              Create a skill (system prompt for processing sessions)
            

            

              yo skill list
              List all skills
            

          


          

            
Shortcuts

            

              ⌘Y
              Show / hide Yo from anywhere
            

            

              ⌘R
              Refresh the active panel
            

            

              ⌘+ / ⌘-
              Zoom in / out. ⌘0 to reset
            

            

              Esc
              Clear the command bar or close this page
