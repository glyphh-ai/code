.yo — agent

Open the agent panel. Ask it anything — it can search notes, navigate panels, click through apps, manage skills, layouts, and more.

.yo Open the agent panel
.yo find that reddit thread Open panel and start searching immediately
.yo open gmail and claude side by side Agent navigates and creates layouts for you
.yo create a skill called summarize Agent manages skills, layouts, and apps

.sup — capture

Capture the active panel into memory.

.sup Capture active panel to memory + clipboard
.sup . formalize Capture + process with a skill

.dip — navigate

Switch between panels, layouts, and connected apps.

.dip claude Switch to a panel
.dip back Switch to the previous panel
.dip split claude gpt Side-by-side panels
.dip split claude gpt / gemini code Multi-row grid — / separates rows

.dip grid — advanced layouts

Full grid control with spans and custom sizing. Commas separate panels, / separates rows.

.dip grid claude,gpt / gemini,code 2×2 grid
.dip grid claude:2,gpt / gemini,code :N = column span — claude takes 2 columns
.dip grid claude|2,gpt / gemini,code |N = row span — claude takes 2 rows
.dip grid [70,30] claude,gpt [%,%] = custom column widths
.dip grid [70,30] [60,40] claude,gpt / gemini,code Custom column widths + row heights
