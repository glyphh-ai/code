Navigation

.Yo is a multi-panel workspace. You can view one app at a time, or split the screen into a grid of panels. Every panel is a live web app running inside .Yo.

Switching panels

Use the .dip command to switch between panels. Type it in the command bar (Cmd+.) or the agent panel.

.dip claudeSwitch to Claude
.dip gmailSwitch to Gmail
.dip backGo to the previous panel

You can also click on tabs in the tab bar to switch panels.

Split view

Put multiple panels side by side with .dip split.

.dip split claude gptTwo panels side by side
.dip split claude gpt / gemini code2×2 grid — / separates rows

URL bar

The URL bar at the top shows the current panel's address. You can type any URL to navigate, or use it as a search bar (searches Google by default). Use Cmd+L to focus it.

Commands

Commands are the core of .Yo. Type them in the command bar (Cmd+.) or chain them together. Every command starts with a dot.

.yo — Agent

Opens the AI agent panel. The agent can search your notes, navigate panels, click through apps, create skills, manage layouts, and more. Ask it anything in natural language.

.yoOpen the agent panel
.yo find my notes about pricingAgent searches your captures
.yo open gmail and claude side by sideAgent navigates and arranges panels

.yo . — Inline process

Processes the last .sup capture with a prompt and injects the result directly into the active text field. No agent panel — just capture, switch, and process.

.yo . summarize thisSummarize and inject into text field
.yo . rewrite as bullet pointsTransform and inject

.sup — Capture

Captures the visible content of the active panel into memory and your clipboard. Use .sup . to also run a skill or prompt on the capture.

.supCapture to memory + clipboard
.sup . formalizeCapture + run the "formalize" skill
.sup . translate to spanishCapture + run a freeform prompt

.dip — Navigate

Switches panels, creates split views, and restores saved layouts.

.dip claudeSwitch to a panel
.dip split claude gptSide by side
.dip layout workspaceRestore a saved layout

.waz — Execute

Runs mapped commands on apps. Each app has commands like grab, compose, search, new, etc.

.waz grabRun "grab" on the active panel
.waz claude newRun "new" on Claude

.drip — Effects

Visual celebration effects. Reward yourself.

Chaining

Commands can be chained together with spaces. Each command runs in sequence.

.dip claude .waz newSwitch to Claude, then start new chat
.sup .dip gpt .yo . explain thisCapture, switch to GPT, process inline

Apps

Apps are web applications that run inside .Yo panels. Each app has an ID, a URL, and a set of mapped commands that the agent and .waz can execute.

Pre-configured apps

.Yo ships with pre-configured apps including ChatGPT, Claude, Gemini, Gmail, Slack, GitHub, Linear, Notion, Grok, Perplexity, YouTube, Reddit, Google Docs, and X. Each has commands mapped to their specific UI elements.

Adding apps

Open the Apps page in this help panel and click + New. Give it an ID (used in commands like .dip myapp), a name, and a URL. You can optionally map commands.

App commands

Commands are actions mapped to specific selectors in the app's DOM. Common commands:

grabExtract the main content as text
inputFocus the text input field
submitClick the send/submit button
newStart a new conversation/document
searchFocus the search bar
composeOpen compose window (email)

Run commands with .waz grab (active panel) or .waz claude grab (specific app). The .yo agent also uses these commands when navigating for you.

Force web mode

Some apps (like ChatGPT, Claude, Gmail) need to run in a web view instead of Electron's BrowserView. This is the "Force Web" toggle — enable it if the app doesn't render correctly.

Skills

Skills are reusable prompt templates that process captured content. Think of them as saved instructions — capture something with .sup, then apply a skill to transform it.

Using skills

.sup . summarizeCapture + run the "summarize" skill
.sup . formalizeCapture + formalize the text
.yo . summarizeProcess last capture with a skill

When you use .sup . skillname, the content is captured and then processed through the skill's prompt template. The result replaces your clipboard content.

When you use .yo . skillname, the result is injected directly into the active text field.

Creating skills

Go to the Skills page in this panel and click + New. Each skill has:

  • Name — the keyword you use to invoke it (e.g., "summarize")
  • Prompt — the instruction template. Use {{input}} as a placeholder for the captured content.

Example prompt: Summarize the following in 3 bullet points:\n\n{{input}}

The .yo agent can also create skills for you — just ask: .yo create a skill called translate that converts text to Spanish

Layouts

Layouts save your panel arrangement so you can restore it later with one command. Save a 3-panel workspace, switch away, and come back to it instantly.

Saving layouts

Arrange your panels the way you want (using .dip split or .dip grid), then save:

.waz layout workspaceSave current arrangement as "workspace"

You can also save layouts from the Layouts page in this panel.

Restoring layouts

.dip layout workspaceRestore the "workspace" layout

This restores the exact panel arrangement, sizes, and apps that were active when you saved.

Grid layouts

For advanced arrangements, use .dip grid with column/row spans and custom sizing:

.dip grid claude,gpt / gemini,code2×2 grid
.dip grid claude:2,gpt / gemini,codeClaude spans 2 columns
.dip grid [70,30] claude,gpt70/30 split

Drag the grid handles between panels to resize them live.

The .Yo Agent

The agent is your AI assistant that lives in the side panel. It can see your panels, navigate apps, search your captures, and execute commands — all through natural language.

What it can do

  • Navigate — switch panels, create layouts, open apps
  • Read — grab content from any panel, extract specific elements
  • Click & type — interact with web apps on your behalf
  • Search — find content in your captured notes and local files
  • Create — make new skills, layouts, and app configurations
  • Write notes — save information to your local note store

Agent modes

The mode selector at the bottom of the agent panel controls how the agent behaves:

askAgent confirms before taking actions (default)
planAgent drafts a plan before executing
autoAgent executes immediately without confirmation

Model selection

The model selector lets you choose which LLM powers the agent. Configure your API key and preferred provider in Settings > Model Configuration.

Chat history

Click the hamburger menu (☰) in the agent panel header to see your conversation history. Each conversation is saved automatically. Click + to start a new chat.
