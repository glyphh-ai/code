yo — capture

            
Grabs content from your panels and sets it as active context.

            

              yo
              Capture all open panels as context (auto-named)
            

            

              yo .
              Capture only the active panel
            

            

              yo summarize this conversation
              Capture all panels + AI formats the result
            

            

              yo . feature-spec
              Active panel only + use a skill or prompt
            

          


          

            
sup — use context

            
Browse your library or paste context into the active app.

            

              sup
              Browse library to pick content as active context
            

            

              sup .
              Paste active context raw — no AI
            

            

              sup . email-format
              Paste context formatted by a skill or prompt
            

          


          

            
dip — navigating

            
Switch between panels, layouts, and connected apps.

            

              dip claude
              Switch to a panel
            

            

              dip back
              Switch to the previous panel
            

            

              dip split claude gpt
              Side-by-side panels
            

            

              dip split claude gpt / gemini code
              Multi-row grid — / separates rows
            

          


          

            
dip grid — advanced layouts

            
Full grid control with spans and custom sizing. Commas separate panels, / separates rows.

            

              dip grid claude,gpt / gemini,code
              2×2 grid
            

            

              dip grid claude:2,gpt / gemini,code
              :N = column span — claude takes 2 columns
            

            

              dip grid claude|2,gpt / gemini,code
              |N = row span — claude takes 2 rows
            

            

              dip grid [70,30] claude,gpt
              [%,%] = custom column widths
            

            

              dip grid [70,30] [60,40] claude,gpt / gemini,code
              Custom column widths + row heights
