yo — creating

Captures content from the active panel and saves it to your library.

yo Save the current session as-is
yo save this but only the last few interactions Natural language — AI grabs and processes what you asked for
yo feature create a feature spec from this conversation Use a skill name or describe what you want

sup — reading

Pulls content from your library back into the active app.

sup Browse all library files
sup pull that feature from yesterday Natural language — AI finds the right file and loads it
sup roadmap Quick search by name

dip — navigating

Switch between panels, layouts, and connected apps.

dip claude Switch to a panel
dip back Switch to the previous panel
dip split claude gpt Side-by-side panels
dip split claude gpt / gemini code Multi-row grid — / separates rows

dip grid — advanced layouts

Full grid control with spans and custom sizing. Commas separate panels, / separates rows.

dip grid claude,gpt / gemini,code 2×2 grid
dip grid claude:2,gpt / gemini,code :N = column span — claude takes 2 columns
dip grid claude|2,gpt / gemini,code |N = row span — claude takes 2 rows
dip grid [70,30] claude,gpt [%,%] = custom column widths
dip grid [70,30] [60,40] claude,gpt / gemini,code Custom column widths + row heights

wassup — creating skills

Create reusable AI skills with natural language instructions.

wassup List available skills
wassup summary extract key points and action items Create a skill — AI writes the prompt for you
wassup translate convert content to Spanish Then use it: yo summary or sup translate
